# Mining Fatigue 3 Fix Fix

> Fix the fix for the mining speed multiplier for Mining Fatigue 3.
>
> 修复对挖掘疲劳 3 挖掘速度乘数的修复。

Mining Fatigue 3 Fix Fix restores the legacy Mining Fatigue mining speed
multipliers in Minecraft 26.3 and later. In
[Minecraft 26.3 Snapshot 3](https://www.minecraft.net/en-us/article/minecraft-26-3-snapshot-3),
Mojang fixed
[MC-279819](https://bugs.mojang.com/browse/MC-279819) by changing the Mining
Fatigue III and higher multipliers. This mod fixes that fix and restores:

- Mining Fatigue III: `0.27%`
- Mining Fatigue IV and higher: `0.081%`

Mining Fatigue 3 Fix Fix 在 Minecraft 26.3 及更高版本中恢复旧版挖掘疲劳的
挖掘速度乘数。Mojang 在
[Minecraft 26.3 Snapshot 3](https://www.minecraft.net/en-us/article/minecraft-26-3-snapshot-3)
中修复了
[MC-279819](https://bugs.mojang.com/browse/MC-279819)，修改了挖掘疲劳 III
及更高等级的倍率。本模组再次修复这项修复并恢复：

- 挖掘疲劳 III：`0.27%`
- 挖掘疲劳 IV 及更高等级：`0.081%`
